# Circulant reproductions from arXiv:1207.3750

These scripts reproduce additional decidable results from Lange, Radziszowski,
and Xu, *Use of MAX-CUT for Ramsey Arrowing of Triangles*,
arXiv:1207.3750.  The SAT encoding uses one Boolean variable per graph edge
and, for every triangle, the two NAE clauses

```text
(a b c)
(-a -b -c)
```

A SAT model is therefore a verified 2-edge-coloring with no monochromatic
triangle, proving that the graph does **not** arrow `(3,3)`.

## Exoo non-arrowing circulants

The following `L(n,s)` graphs use the multiplicative subgroup generated by
`s` modulo `n`.  Each connection set is checked to contain `-1 mod n`, so the
graph is undirected.

```text
graph    vertices  degree  edges   triangles
L(17,2)       17       8      68          68
L(61,8)       61      20     610        1220
L(79,12)      79      26    1027        2054
L(421,7)     421      70   14735       58940
L(631,24)    631     126   39753      185514
```

Each graph's arrowing CNF was solved by Kissat with status `SATISFIABLE`.
The model was independently re-read by `verify_witnesses.py`, which checks
every triangle contains both Boolean colors.  Thus each model is a direct,
machine-checkable certificate that the corresponding graph is non-arrowing,
matching the credited Exoo results.

The exact Kissat status lines were:

```text
L17_2:  s SATISFIABLE
L61_8:  s SATISFIABLE
L79_12:  s SATISFIABLE
L421_7: s SATISFIABLE
L631_24:s SATISFIABLE
```

The independently coded verifier reported `[PASS]` for all five witnesses.
The raw solver logs and model files are retained beside the CNFs.

```text
graph    vertices  degree  edges   triangles  K4-free

L(761,3)     761     152   57836      347016     True
```

Kissat results:

```text
           process-time in Kissat log: 1188.75 seconds
L(761,3): s SATISFIABLE
           process-time in Kissat log: 47.05 seconds
```

The `L(761,3)` model was independently reconstructed and checked:

```text
L761_3: independently verified SAT witness

```

Thus `L(761,3)` is certified non-arrowing.  `L(457,6)` remains undecided
within the stated budget; it must not be interpreted as SAT or UNSAT.
Neither additional instance produced an UNSAT result, so no DRAT proof was
applicable and no improved Folkman bound is claimed.

## Structural record-family graphs

`G941 = G(941,5)` uses the fifth-power residue connection set.  The
independent set construction checks that `-1` is a fifth power residue.

```text
vertices = 941
degree   = 188
edges    = 88454
triangles= 707632
K4-free = True
```

`G860` is the induced subgraph of `G941` after removing

```text
C(d=2,k=81) = {0,2,4,...,160}.
```

Its independently verified structural data are:

```text
vertices = 860
edges    = 73981
triangles= 542514
K4-free = True
```

K4-freeness is checked directly by testing every edge inside every
neighborhood for a triangle.

## Scope and caveat

These artifacts reproduce known decided results and structural claims.  They
do not change any open bound and do not establish a new or improved Folkman
bound.  In particular, the SAT witnesses certify non-arrowing for the five
Exoo circulants, while the `G941` and `G860` checks certify only their reported
graph sizes, triangle counts, and K4-freeness; no arrowing claim is made for
those two structural targets.
